# 🌍 Solar System Presentation

An interactive, visually stunning presentation about the Solar System.

## Features

✨ **12 Comprehensive Slides** covering:
- Title Slide
- Solar System Overview
- The Sun
- All 8 Planets (Mercury, Venus, Earth, Mars, Jupiter, Saturn, Uranus, Neptune)
- Key Takeaways

🎨 **Beautiful Design**
- Dark space-themed gradient background
- Golden accents mimicking the sun
- Smooth slide transitions
- Fully responsive design

⌨️ **Multiple Navigation Options**
- Click Previous/Next buttons
- Use arrow keys (← →)
- Slide counter display

📱 **Responsive Layout**
- Works on desktop, tablet, and mobile devices
- Optimal viewing experience at any screen size

## How to Use

1. Open `index.html` in your web browser
2. Navigate through slides using:
   - Previous/Next buttons
   - Arrow keys on your keyboard
3. View detailed information about each planet

## File Structure

```
├── index.html    # Main presentation HTML
├── styles.css    # Styling and animations
├── script.js     # Navigation and interactivity

```

## Slides Overview

1. **Title Slide** - Introduction with animated sun
2. **Overview** - General facts about the solar system
3. **The Sun** - Star information and composition
4. **Mercury** - Closest planet to the sun
5. **Venus** - Hottest planet with thick atmosphere
6. **Earth** - Our home planet
7. **Mars** - The red planet with rover exploration
8. **Jupiter** - Largest planet with Great Red Spot
9. **Saturn** - Planet with magnificent rings
10. **Uranus** - Ice giant that rotates on its side
11. **Neptune** - Farthest planet with fastest winds
12. **Key Takeaways** - Summary and future exploration
